# Security policy

## Supported versions

Security fixes go into the latest release. Update to it before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability reporting:

https://github.com/ekamran/wp-cli-http-proxy-command/security/advisories/new

Include the package version, your WP-CLI and PHP versions, and the steps to reproduce the problem. Do not include real proxy credentials.
